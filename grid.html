CSS Grid

Aprendendo a organizar elementos em linhas e colunas

Início Flexbox Grid

O que é Grid?

CSS Grid é uma ferramenta que permite organizar os elementos de um site em linhas e colunas. Ele facilita a criação de layouts e a divisão do espaço da página.

Principais propriedades

Display: grid

Ativa o sistema Grid em um elemento.

Grid-template-columns

Define quantas colunas vão existir e o tamanho de cada uma.

Grid-template-rows

Define as linhas e seus tamanhos.

Gap

Define o espaço entre as linhas e colunas.

Frações (fr)

A unidade fr divide o espaço disponível entre as colunas ou linhas.

Outras propriedades

Podemos usar repeat() para repetir colunas, minmax() para definir tamanhos mínimos e máximos, e grid-column ou grid-row para definir quanto espaço um elemento vai ocupar.
