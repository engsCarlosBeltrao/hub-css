O que é Flexbox?

Flexbox é uma ferramenta do CSS que ajuda a organizar os elementos de uma página. Com ele, podemos alinhar e distribuir os itens de maneira mais fácil.

Principais propriedades

Display: flex

Ativa o Flexbox dentro de um elemento.

Flex-direction

Define se os elementos vão ficar em linha ou em coluna.

Justify-content

Organiza os elementos no eixo principal.

Align-items

Alinha os elementos no eixo transversal.

Gap

Define o espaço entre os elementos.

Outras propriedades

Também existem propriedades como flex-wrap, que permite quebrar os elementos para outra linha, flex-grow, que permite aumentar o tamanho de um item, e flex-shrink, que controla a redução dos elementos.
